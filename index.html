Message Tracing Infrastructure

Post Office is Atlassian's centralized messaging platform — it routes notifications, emails, and in-app messages across every Atlassian product. Before my work, debugging message delivery failures was extremely time-consuming because there was no way to follow a single message through the system.

  • Designed and implemented message tracing in TypeScript, propagating unique trace IDs through a 6-stage delivery pipeline (ingestion → validation → routing → template rendering → channel selection → delivery)
  • Each trace ID travels with the message payload at every stage, enabling engineers to reconstruct the full journey of any message from a single identifier
  • The tracing system handles both real-time delivery via AWS SQS-based queues and on-demand delivery paths, each with different latency characteristics and failure modes

Observability Dashboard

  • Built a Databricks SQL dashboard aggregating delivery outcome data across all pipeline stages, enabling failure diagnosis across channels (email, push, in-app, SMS)

ML Pipeline Instrumentation

  • Implemented set-difference analysis to infer dropped messages — by comparing candidate sets at each ranking stage, the system can identify exactly which messages were filtered and why
  • This was particularly valuable because the ranking pipeline operates as a series of filters, and before instrumentation there was no visibility into messages lost between stages

Opscribe

A full-stack infrastructure intelligence platform that models cloud systems as typed dependency graphs, enabling multi-hop impact analysis and AI-powered infrastructure reasoning.

React TypeScript FastAPI PostgreSQL pgvector LangChain Llama 3.3

What It Does

Opscribe lets you model cloud infrastructure as a typed dependency graph — services, databases, queues, load balancers, and their relationships are all represented as nodes and edges. From this graph, you can ask questions like "what happens if this database goes down?" and get real answers.

Graph Analysis Engine

  • Engineered BFS and DFS graph traversal algorithms for multi-hop dependency resolution, reverse impact tracing, and blast-radius analysis
  • The system can trace upstream and downstream dependencies across any number of hops, showing exactly which services would be affected by an outage

RAG Pipeline with pgvector

  • Built a Retrieval-Augmented Generation (RAG) pipeline using pgvector to embed and retrieve source code, Terraform configurations, and infrastructure documentation via semantic search
  • This allows the AI agent to ground its responses in actual infrastructure code rather than hallucinating configurations

AI Agent

  • Developed a Llama-3.3-70B LangChain agent that combines graph traversal tools with RAG retrieval for infrastructure analysis and IaC (Infrastructure as Code) generation
  • The agent can answer natural-language questions about system architecture, generate Terraform code, and explain blast radius for proposed changes
